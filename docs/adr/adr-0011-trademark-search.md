# ADR-0011: Trademark search results — go on "Fotobase"

**Date:** 2026-10-20 · **Status:** accepted (task 00-007)

## Context

PLAN §12 requires EUIPO, USPTO, and DPMA searches before the first public commit; a live conflicting mark would trigger a rename (ADR-0004).

## Decision

Owner-run searches of EUIPO, USPTO, and DPMA for "fotobase" (2026-10-20): **no conflicting marks found — go on the name.**

## Consequences

- Name is cleared for the first public commit; weak protectability of a descriptive coin remains accepted (ADR-0004) — the moat is the product.
- No rename path open; diligence items 00-005/00-006 are the only remaining pre-commit notes, both descoped in ADR-0010.
