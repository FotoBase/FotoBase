# ADR-0004: Project name "Fotobase"

**Date:** 2026-10-20 · **Status:** accepted (PLAN §11 Q3) — diligence pending before first public commit

## Context

The name must avoid Picasa/Picasso trademark and npm/Android collisions, read naturally in DE/NL/Nordics, and be available as an org/domain.

## Decision

"Fotobase" (photo + database). Rejected after checking: Mynd, Safelight, Calotype, Fovea, Albumen, Bowerbird, Eidetic, Mneme, Jackdaw, Argentic, Attic, Tablinum, Atget, Magpie, Myna, Hoopoe, Kittiwake, Gannet, Manul.

## Consequences

Descriptive coin, near-zero conflict risk, instantly understood; weak trademark protectability accepted — the moat is the product, not the name. Blocking diligence (GitHub org, crates.io, npm, domain, trademark registries) tracked as tasks 00-005…00-007.
